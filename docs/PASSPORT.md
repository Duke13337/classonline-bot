## Краткое описание

Онлайн-школа «КлассОнлайн» принимает обращения учеников и родителей в личных сообщениях Telegram. Сообщения теряются в переписке, а администратор не видит общей статистики. Разработанный бот становится единой точкой входа: пользователь выбирает тип обращения, указывает имя и контакт, описывает запрос и подтверждает отправку. Заявка сохраняется в SQLite, получает номер, а администратор сразу получает уведомление.

## Что реализовано

- Три типа обращений: запись на занятие, вопрос по курсу, прочее.
- Пошаговый диалог на aiogram FSM с проверкой ввода и отменой.
- База SQLite: таблица `applications` на 9 полей и 2 индекса.
- Уведомления администраторам из `ADMIN_IDS`.
- Команды `/stats`, `/applications [N]`, `/export` (CSV для Excel).
- 40 автотестов: валидация, база, тексты, экспорт.
- Документация, презентация и демонстрационная база на 14 заявок.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python -m bot
```

Перед запуском указать в `.env` токен от `@BotFather` и Telegram ID администраторов в `ADMIN_IDS`.
