# Руководство пользователя

## 1. Для учеников и родителей

### Как начать

1. Откройте бота в Telegram.
2. Отправьте `/start`.
3. Выберите тип обращения:
   - **📝 Запись на занятие** — подобрать занятие или записаться на пробный урок;
   - **❓ Вопрос по курсу** — расписание, формат, оплата, материалы;
   - **💬 Прочее** — любая другая просьба или предложение.

### Как заполнить заявку

| Шаг | Что нужно сделать |
|---|---|
| 1 | Выбрать тип обращения кнопкой |
| 2 | Написать имя и фамилию |
| 3 | Указать телефон, e-mail или `@username` |
| 4 | Описать запрос: предмет, класс, удобное время |
| 5 | Проверить сводку и нажать **✅ Отправить** |

После отправки бот покажет номер заявки и дату. Администратор свяжется с вами по указанному контакту.

### Что можно вводить в поле «Контакт»

- телефон: `+7 900 123-45-67`, `8 (900) 123-45-67`;
- e-mail: `student@example.com`;
- Telegram: `@class_online`.

### Если бот не принимает ввод

| Сообщение | Что делать |
|---|---|
| «Имя слишком короткое» | указать имя и фамилию, минимум 2 символа |
| «Не похоже на контакт» | проверить телефон, e-mail или `@username` |
| «Слишком короткое сообщение» | описать запрос подробнее, минимум 5 символов |
| «Слишком длинное сообщение» | сократить текст до 1000 символов |
| «Пожалуйста, отправьте ответ текстом» | отправить текстовое сообщение вместо фото или стикера |

### Отмена

- нажать **✖️ Отмена** под сообщением;
- или отправить `/cancel`.

Заявка не сохранится, бот вернёт главное меню.

### Полезные команды

| Команда | Действие |
|---|---|
| `/start` | главное меню |
| `/help` | справка |
| `/cancel` | отменить заполнение |

## 2. Для администратора

### 2.1. Настройка

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. Скопируйте `.env.example` в `.env`:

```env
BOT_TOKEN=123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
ADMIN_IDS=123456789
DB_PATH=data/applications.db
```

Несколько администраторов указываются через запятую:

```env
ADMIN_IDS=123456789,987654321
```

4. Установите зависимости и запустите бота:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m bot
```

### 2.2. Команды

| Команда | Что показывает |
|---|---|
| `/stats` | всего заявок, новых, за 7 дней, разбивку по типам |
| `/applications` | 5 последних заявок |
| `/applications 10` | 10 последних заявок (максимум 20) |
| `/export` | CSV-файл со всеми заявками |

Пример `/stats`:

```text
📊 Статистика заявок

Всего: 14
Новых: 9
За 7 дней: 10

По типам
• Запись на занятие — 7
• Вопрос по курсу — 4
• Прочее — 3
```

### 2.3. Уведомления

При каждой новой заявке администратор получает сообщение:

```text
🔔 Новая заявка №14

Дата: 14.11.2026 20:36
Тип: Запись на занятие
Имя: Роман Захаров
Контакт: +7 926 111-22-33
Telegram: @user_14

Сообщение
Запишите на пробное занятие по математике, 7 класс.
```

Если у пользователя нет username, в поле Telegram будет `—`.

### 2.4. Работа с базой

Файл базы по умолчанию — `data/applications.db`. Он создаётся автоматически.

Посмотреть заявки можно любым SQLite-клиентом:

```sql
SELECT id, created_at, full_name, contact, type, status
FROM applications
ORDER BY id DESC
LIMIT 20;
```

Отметить заявку обработанной:

```sql
UPDATE applications SET status = 'processed' WHERE id = 14;
```

### 2.5. Резервная копия

Остановите бота и скопируйте файл базы:

```powershell
Copy-Item data\applications.db backups\applications_2026-11-14.db
```

Или выгрузите CSV командой `/export`.

### 2.6. Демонстрационный режим

Чтобы показать бота на готовых данных, укажите в `.env`:

```env
DB_PATH=data/demo.db
```

В демо-базе 14 заявок. Вернуть рабочую базу — снова указать `data/applications.db`.

## 3. Частые проблемы

| Проблема | Причина | Решение |
|---|---|---|
| `Не задан BOT_TOKEN` | нет `.env` или пустой токен | скопировать `.env.example` в `.env`, вписать токен |
| Бот не отвечает | неверный токен или нет сети | проверить токен, доступ к `api.telegram.org` |
| «Команда доступна только администратору» | ID нет в `ADMIN_IDS` | добавить ID, перезапустить бота |
| `database is locked` | база открыта другим процессом | закрыть лишние подключения, перезапустить бота |
| Кириллица в CSV не читается | файл открыт не в Excel | использовать `/export`: файл уже с BOM |
| Заявка не сохранилась | не пройдена валидация | исправить поле по подсказке бота |

---

## 4. Ограничения

- Черновики незавершённых заявок хранятся в памяти и теряются при перезапуске.
- Статусы заявок меняются через базу данных, отдельной команды пока нет.
- Бот рассчитан на последовательную обработку и небольшой поток обращений.
