# Данные

| Файл | Назначение |
|---|---|
| `demo.db` | демонстрационная база: 14 заявок за последние 10 дней |
| `applications.db` | рабочая база, создаётся при первом запуске и не попадает в Git |

Демо-база нужна для презентации и проверки команд администратора. Чтобы бот работал с ней, укажите в `.env`:

```env
DB_PATH=data/demo.db
```

Пересоздать демо-базу:

```bash
python scripts/seed_demo.py
```

Содержимое демо-базы:

- всего заявок — 14;
- новых — 9;
- за последние 7 дней — 10;
- по типам — 7 «Запись на занятие», 4 «Вопрос по курсу», 3 «Прочее».
